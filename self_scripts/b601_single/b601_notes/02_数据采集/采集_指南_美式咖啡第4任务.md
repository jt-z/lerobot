# 美式咖啡（第 4 条任务）采集指南

新脚本：`self_scripts/b601_single/06_record_make_americano.sh`
参照 `05_record_place_cup.sh` 编写，链路（CAN 复位、主臂探测、三路相机、校准检查、h264 视频、`--resume` 续录、SIGPIPE 处理）完全一致，只把「多区域循环」换成「单任务」。

## 一、任务定义

| 项 | 内容 |
|---|---|
| 中文 | 操作全自动咖啡机制作美式咖啡，按动按钮控制为中杯水量和中等咖啡浓度 |
| 英文 prompt | 见下方代码块（训练 / 推理必须逐字一致） |
| 阶段 | 接咖啡流程的第 4 条任务，排在「取杯接咖啡」（02）和「分区放杯」（05）之后 |
| 数据集 | `b601_americano_<时间戳>` |

```
Use the gripper tip to press the buttons on the automatic coffee machine to select a medium cup size and medium coffee strength, then start brewing an Americano
```

prompt 设计要点（与 02 / 05 的风格对齐）：

- 英文祈使句，不用 `please / then` 之类冗余词；
- 「动作（按按钮）+ 目标设置（中杯 / 中等浓度）+ 启动制作」压在一句里，避免分阶段歧义；
- 约 31 词 / 60 token 以内，不会被 π0.5 的 tokenizer 截断。


## 五、采集流程与要点

每个 episode：

1. 按 `n` 开始（或等待 reset 结束自动开始）；
2. 用夹爪尖端依次按动咖啡机面板，选出杯量＝中杯、浓度＝中等；
3. 按启动键开始萃取，等动作稳定后按 `n` 结束并保存；
4. reset 阶段：把咖啡机设置复位、杯子/机械臂恢复起点，进入下一集。

要点：

- **每集必须复位设置**：如果上一集的「中杯 / 中等」还留着，下一集开头就没有「按按钮选择」的演示，轨迹分布会和第一集不一致。
- **按按钮用夹爪尖端轻按**，不要持续压在面板上（容易过载或误触长按）。
- **每集起点尽量一致**，物体位置可以有轻微变化以增加泛化。
- **中途退出**（`q` / Ctrl+C）只会丢当前这一集，已保存的集不会受影响；续录用 `--resume`。

## 七、同步推理脚本（容易漏）

新 prompt 必须进 `lx/pi05_inference.sh` 的 `TASKS` 数组（当前只有 4 条，顺序 0=取杯接咖啡、1/2/3=放杯区），否则推理时送进去的是旧任务文本：

```bash
# lx/pi05_inference.sh 的 TASKS 数组追加第 5 条
"Use the gripper tip to press the buttons on the automatic coffee machine to select a medium cup size and medium coffee strength, then start brewing an Americano"
```

之后：

```bash
TASK_INDEX=4 bash lx/pi05_inference.sh 007000
```

若要把新任务并入训练集（类似 `b601_mixed`），合并后记得同步更新 `TASKS` 的顺序与文本，训练/推理两边必须逐字一致。
