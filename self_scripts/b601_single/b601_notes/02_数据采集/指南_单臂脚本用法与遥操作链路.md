# 单臂脚本用法与遥操作链路

目的：把 `self_scripts/b601_single/` 下 01~06 各脚本「干什么、怎么用、参数从哪来」一次说清，并记录 01 遥操作的真实控制链路。

适用机器：`kfzbox`（RTX 3060 12GB，设备档案 `devices/kfzbox.sh`）。

## 一、脚本清单

| 脚本 | 用途 | 是否录数据 | 数据/日志落点 |
|---|---|---|---|
| `01_teleop.sh` | 纯遥操作：主臂拖动 → 从臂跟随 | 否 | `_logs/` 无 |
| `02_record.sh` | 主采集：取杯 → 放托盘 → 按按钮 → 回零位（单 prompt） | 是 | `~/b601_data/b601_<时间戳>/` |
| `03_replay.sh` | 回放已录 episode（下发绝对目标角，验证轨迹可复现） | 否 | `_logs/replay_b601_*.log` |
| `04_dagger_collect.sh` | DAgger 扩充：策略自主跑 + 人工纠偏 | 是 | 依赖 z790 上的权重路径，本机需改 |
| `05_record_place_cup.sh` | 分区放杯，1/2/3 号区各一条 prompt，写进同一数据集 | 是 | 仓库根 `b601_place_cup_<时间戳>/` |
| `06_record_make_americano.sh` | 按按钮做美式（中杯 + 中等浓度） | 是 | 仓库根 `b601_americano_<时间戳>/` |
| `b601_common/07_preflight.sh` | 上机前体检（环境/CAN/电机扫描/主臂/相机/校准） | 否 | 仅终端输出 |

所有入口脚本都会先 source `b601_common/_env.sh`，参数按「设备档案 `devices/<host>.sh` → `_defaults.sh` → 脚本默认值」三层取值。

## 二、01_teleop.sh（遥操作）

```bash
bash self_scripts/b601_single/01_teleop.sh
```

**脚本做的事（按执行顺序）**

1. `_env.sh` 按 `hostname` 选设备档案，导出 python 环境、主臂串口、相机序列号、关节方向。
2. 组装 `FOLLOWER_ID= follower` / `LEADER_ID=leader` / `can0` / `gravity_compensation=true` / `joint_directions` 全 `-1.0`。
3. `B601_DISPLAY_DATA=1`（默认）时生成三路相机 YAML（hand / front / top）并导出 `DISPLAY`。
4. 检查 `lerobot-teleoperate` 是否存在（本机靠 `_env.sh` 把环境 bin 加进 PATH；脚本里 `conda activate lerobot` 兜底在本机是死代码）。
5. **CAN 复位**：`can0` down → 1Mbps → up → 等 0.5s → `candump` 排空残留帧，再确认 UP 且 bitrate 正确。
6. 检查主臂串口存在（必要时 `chmod 666`）。
7. 检查两侧校准文件：`seeed_b601_rs_follower/follower.json`、`rebot_102_leader/leader.json`。
8. 打印安全须知，**停在 `按 ENTER` 等人工确认**。
9. 执行 `lerobot-teleoperate`，`tee` 到 `_logs/`，`trap '' PIPE` 保证 Ctrl+C 时仍走断开清理。

**实际下发的命令**

```bash
lerobot-teleoperate \
  --robot.type=seeed_b601_rs_follower --robot.id=follower \
  --robot.port=can0 --robot.can_adapter=socketcan \
  --robot.gravity_compensation=true \
  --robot.joint_directions="{shoulder_pan: -1.0, ..., gripper: -1.0}" \
  --robot.cameras="{hand: ..., front: ..., top: ...}" \
  --teleop.type=rebot_102_leader --teleop.id=leader \
  --teleop.port=/dev/rebot_leader \
  --display_data=true --display_mode=rerun
```

**控制链路**

```
robot.connect()
  ├─ 打开 can0，按 motor_can_ids 加电机
  ├─ 校准文件已存在 → 跳过重标（不会弹校准提示）
  ├─ 三路相机 connect
  ├─ configure() → bus.enable_all()      ← 从臂此刻上电变硬
  └─ 建重力补偿 URDF 配对

loop @60Hz（脚本没传 --fps，默认 60）
  obs  = robot.get_observation()          # 关节角 + 图像
  raw  = teleop.get_action()              # 主臂舵机读角 → 主臂侧 joint_directions（夹爪 -6）
  robot.send_action(raw)
       × 从臂 joint_directions（全 -1）
       → 按 joint_limits 裁剪（shoulder_pan ±145、gripper 0~270 …）
       → 温度检查（115 告警 / 125 过热 / 135 紧急失能）
       → 六轴 MIT + 重力前馈；夹爪走 FORCE_POS
  rerun 显示三路画面 + 关节数值

finally
  teleop.disconnect() → robot.disconnect()
  → safe_zero() 回零位 → 失能
```

关键结论：

- **是关节角直通，不是 IK 映射**。主臂输出已对齐到 B601 的关节单位，从臂只做符号翻转 + 限位裁剪。
- 夹爪方向链：主臂内部 `-6` 把舵机量程映射到 `[-270, 0]`，从臂再乘 `-1` 得到 `[0, 270]`，正好落在从臂限位内。所以 `gripper: -1.0` 不能改。
- 脚本**没有传 `--robot.max_relative_target`** → 无速度限幅，跟手直连。
- `Ctrl+C` 后从臂会自己走回坐姿再失能，退出时别扶着。

**安全红线**

1. 按 ENTER 前把主臂和从臂都摆到零位，夹爪合到 0°。
2. 从臂连接后立即变硬并跟随主臂，第一次请小幅慢速确认方向。
3. 紧急停止 = 切断从臂 48V 电源。
4. 退出时 `safe_zero` 只把夹爪收到夹稳位，不会回收纳 0°；下次启动前手动把夹爪合到 0°，否则零点基准会偏。

## 三、02_record.sh（主采集）

```bash
bash self_scripts/b601_single/02_record.sh
```

前置：从臂电机在线、主臂上电、两侧校准文件存在、主从臂在零位且夹爪闭合。

脚本自动完成：CAN 复位 → 主臂串口自动探测（真正 ping 舵机 0~6，不会误认其它串口）→ 三路相机检查 → 校准文件检查 → 参数总览 → **停在 `按 ENTER 开始采集`**。

**录制按键（焦点必须在终端）**

| 键 | 作用 |
|---|---|
| `n` / `→` | 本集演示完成，结束并保存 |
| `r` / `←` | 丢弃当前这一集，重录 |
| `q` / `Esc` | 停止整个录制 |
| `Ctrl+C` | 中止；从臂回零位后失能 |

单集流程：开始录 → 操作 → `n` 保存 → 重置环境等 5s（再按 `n` 可跳过）→ 自动下一集。

**默认参数（改脚本头部）**

| 项 | 默认 | 位置 |
|---|---|---|
| 任务描述 | 取杯 / 放托盘 / 按左侧第一个常亮按钮 / 回零位（英文） | `:145` |
| 集数 | 120 | `:146` |
| 单集上限 / 重置 | 600s / 5s | `:152-153` |
| FPS | 30 | `:155` |
| 视频 | h264 | `:322-323` |
| 推 Hub | `false`（本地保存） | `:134` |

**数据落点**

```
~/b601_data/b601_<YYYYmmdd_HHMMSS>/
  meta/info.json     # total_episodes / total_frames / tasks
  data/              # 每集 parquet
  videos/            # hand / front / top
```

`repo_id` 与目录名同为一个带时间戳的名字，靠 `--dataset.no_stamp=true` 防止再叠一层时间戳。日志：`self_scripts/_logs/record_b601_<时间>.log`（日志里的 `argv` 段完整记录了当次 repo_id / root / 相机 / prompt，是最可靠的溯源依据）。

**续录**

```bash
ls -dt ~/b601_data/b601_* | head    # 先查会话名
bash self_scripts/b601_single/02_record.sh --resume b601_20261117_143000        # 续到目标集数
bash self_scripts/b601_single/02_record.sh --resume b601_20261117_143000 60     # 本次再补 60 集
```

**常改的环境变量（不必改文件）**

```bash
B601_DISPLAY_DATA=0   bash .../02_record.sh                                    # 关画面
B601_LEADER_PORT=/dev/ttyACM0 bash .../02_record.sh                            # 手动指定主臂口
B601_DATA_ROOT=/home/jt/dev/lerobot bash .../02_record.sh --resume b601_1      # 临时换数据根
```

## 四、03_replay.sh（回放 episode）

```bash
ls -dt ~/b601_data/b601_* | head -1
DATASET_ROOT=$(ls -dt ~/b601_data/b601_* | head -1) EPISODE=0 \
  bash self_scripts/b601_single/03_replay.sh
```

注意：

- 脚本默认 `DATASET_ROOT` 还是 z790 的 `/home/kf/...`，**本机必须显式传**。
- `EPISODE` 默认就是 `0`。
- 脚本会打印该 episode 的首帧 `state` / `action`，这就是它要甩过去的绝对目标姿态；按 ENTER 前先把从臂摆到接近首帧，否则会猛甩。
- 默认 `USE_RERUN=1` 走 `b601_common/06_replay_rerun.py`，支持键盘控制：`p` 暂停、`r` 继续、`←/→` 按回放速度慢速倒退/前进 2s、`v` 开关画面。固定 `b601_1` ep44 的回放入口是 `lx/replay_task1_ep44.sh`，细节见 [episode 回放与键盘控制](指南_episode回放与键盘控制.md)。
- `USE_RERUN=0` 关相机与画面，等价于原生 `lerobot-replay`（只动臂、不读相机），此时没有键盘控制。
- 回放不录数据，结束时 `safe_zero` 回零位。

只看数据、不动机械臂：

```bash
ls ~/b601_data/b601_*/videos/*/episode_000000.mp4
python3 -c "import json;d=json.load(open('路径/meta/info.json'));print(d['total_episodes'],d['total_frames'],d['fps'])"
```

## 五、04 / 05 / 06 简述

| 脚本 | 与 02 的差异 |
|---|---|
| `04_dagger_collect.sh` | 走 `lerobot-rollout --strategy.type=dagger`：策略自主跑、人工按 Tab 纠偏，自主帧和纠偏帧都录。**本机跑不了**：`MODEL_PATH`、`DAGGER_ROOT` 仍是 z790 的 `/home/kf/...`，需改成本机权重与目录。 |

## 六、变更记录

**2026-11-17：`02_record.sh` 数据根改回 `B601_DATA_ROOT`**

- 原实现：`DATA_ROOT="${B601_REPO_ROOT:-仓库根}"`，新采集会写进 `/home/jt/dev/lerobot/b601_<时间戳>/`，和代码混在一起。
- 现实现：`DATA_ROOT="${B601_DATA_ROOT:-$HOME/b601_data}"`，kfzbox 落 `~/b601_data`，z790 仍跟设备档案走 `~/LX/pai0/b601_data`，一处改动两台机器都对。
- 影响：`--resume` 也按同一 `DATA_ROOT` 找会话，仓库根下的老数据集（`b601_1` / `b601_2` / `b601_mixed`）要续录需 `B601_DATA_ROOT=/home/jt/dev/lerobot` 临时指回去。
- `05` / `06` 仍落仓库根，未改。
