## 四、100 份 `rollout_*` 是什么

这些是**推理回放录制**（`lerobot-rollout` 的 base 策略输出），不是训练数据：

| 前缀 | 内容 |
|---|---|
| `rollout_b601_so101_make_coffee_act_*` / `rollout_b601_make_coffee_act_50k_*` | B601 取杯接咖啡，ACT 15k / 50k 权重 |
| `rollout_b601_so101_pi0_20k_*` | 同一任务，pi0 20k |
| `rollout_cap_pen_two_hand_*` | 双臂帽笔任务，ACT / pi0_20k / SmolVLA 4k、30k、110k |
| `rollout_coffee_cup_button_act_*` / `_smolvla_*` | 咖啡机按钮任务，两种策略对比 |

大部分只有 `meta/` 甚至完全不完整（含 `tmp*` 临时目录），属于排障/效果验证的副产物，**不要拿来训练**。

## 五、一行命令重新统计

```bash
python3 - <<'EOF'
import json, glob
for p in sorted(glob.glob('/home/jt/.cache/huggingface/lerobot/*/*/meta/info.json')):
    d = json.load(open(p))
    repo = p.split('/lerobot/')[1].split('/meta/')[0]
    print(f"{repo:55s} {d['robot_type']:26s} eps={d['total_episodes']:<5d} "
          f"frames={d['total_frames']:<8d} fps={d['fps']}")
EOF
```

仓库根目录的三份用同样方式读取，把 glob 换成 `/home/jt/dev/lerobot/b601_*/meta/info.json`。

## 六、结论

- 真正能直接训练的：`b601_mixed`（4 任务 220 集）、`hellozjt/cap_pen_and_put_into_holder`（40 集）、`hellozjt/coffee_cup_button_20260826_232220`（118 集）。
- 数据集命名与 prompt 强绑定：换任务就是新建一份数据集，不要往 `b601_mixed` 里直接追加不同 prompt 的数据（详见 [采集脚本溯源](../02_数据采集/采集_指南_脚本溯源.md)）。
- 统计以 `meta/info.json` 为准；目录存在 ≠ 数据可用（见上面 3 个残缺目录）。
