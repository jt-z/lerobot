## 🔴 核心问题

### 问题1：目标位置超出安全范围，被持续裁剪

日志显示大量的警告信息：

```
WARNING Relative goal position magnitude had to be clamped to be safe.
{   'elbow_flex': {   'original goal_pos': 99.63,
                      'safe goal_pos': 99.12},
    'shoulder_lift': {   'original goal_pos': -98.22,
                         'safe goal_pos': -98.13},
    'wrist_flex': {   'original goal_pos': 60.17,
                      'safe goal_pos': 55.99}}
```

**根本原因**：
- `max_relative_target=0.3` 的安全限制太严格
- Leader 和 Follower 的**初始位置差距过大**
- 系统不断裁剪目标位置，导致 Follower 无法到达 Leader 的目标位置

### 问题2：配置文件可能存在 ID 冲突

脚本中的配置：

```bash
# collect_cap_pen_data.sh 第119行
--robot.id=jt_follower_arm          # Follower 的 ID

# 第127行
--teleop.id=jt_leader_arm           # Leader 的 ID
```

但日志显示：
```
INFO jt_follower_arm_left SOFollower connected.
INFO jt_follower_arm_right SOFollower connected.
INFO jt_leader_arm_left SOLeader connected.
INFO jt_leader_arm_right SOLeader connected.
```

**潜在问题**：
- 左右臂可能共享同一个校准文件 `jt_follower_arm.json`
- 如果左右臂物理位置不同，共享校准文件会导致初始位置不匹配

## 🔍 问题分析

### 工作机制

双臂遥操作的正常流程：

```
1. 读取 Leader 臂位置 (teleop.get_action())
2. 计算相对目标位置 = Leader 位置 - Follower 当前位置
3. 检查安全限制：
   if abs(相对目标位置) > max_relative_target:
       裁剪到 max_relative_target 范围内
4. 发送到 Follower 执行
```

### 当前情况

**Leader 位置**：`elbow_flex = 99.63°`  
**Follower 当前位置**：估计约 `0°` (未明确显示)  
**相对目标**：`99.63 - 0 = 99.63°`  
**安全限制**：`max_relative_target = 0.3` (以归一化单位计算)  
**实际发送**：被裁剪到极小值 `99.12°` (几乎不动)

**结果**：Follower 每次只能移动一点点，看起来像"不动"

## 💡 解决方案

### 方案1：调整初始位置（推荐）

**在开始录制前，手动将 Follower 移动到与 Leader 相似的初始位置。**

**步骤**：
1. 按 Ctrl+C 中断当前录制
2. **禁用 Follower 的扭矩**：
   ```bash
   # 进入 Python 交互模式
   python
   ```
   
   ```python
   from lerobot.robots.so_follower import SOFollower
   from lerobot.robots.so_follower.config_so_follower import SOFollowerConfig
   
   # 连接左臂 Follower
   left_config = SOFollowerConfig(port="/dev/ttyLeftFollower")
   left_follower = SOFollower(left_config)
   left_follower.connect()
   left_follower.bus.disable_torque()  # 禁用扭矩
   
   # 连接右臂 Follower
   right_config = SOFollowerConfig(port="/dev/ttyRightFollower")
   right_follower = SOFollower(right_config)
   right_follower.connect()
   right_follower.bus.disable_torque()  # 禁用扭矩
   
   print("✅ 现在可以手动移动 Follower 到合适位置")
   print("移动完成后，按 Ctrl+D 退出")
   ```

3. **手动移动 Follower 到与 Leader 相似的姿态**
4. 退出 Python
5. 重新运行采集脚本

### 方案2：增大 max_relative_target（临时方案）

修改脚本第122-123行：

```bash
# 原配置
--robot.left_arm_config.max_relative_target=0.3 \
--robot.right_arm_config.max_relative_target=0.3 \

# 修改为
--robot.left_arm_config.max_relative_target=1.0 \
--robot.right_arm_config.max_relative_target=1.0 \
```

**警告**：这会降低安全性，如果 Leader 突然大幅移动，Follower 会快速响应，可能造成碰撞。

### 方案3：分别校准左右臂（长期方案）

**问题根源**：左右臂可能共享同一个校准文件，但物理初始位置不同。

**解决步骤**：

1. 为左右臂创建独立的校准文件：
   ```bash
   # 创建左臂校准文件
   python lerobot/scripts/calibrate_robot.py \
     --robot.type=so_follower \
     --robot.port=/dev/ttyLeftFollower \
     --robot.id=jt_follower_arm_left
   
   # 创建右臂校准文件
   python lerobot/scripts/calibrate_robot.py \
     --robot.type=so_follower \
     --robot.port=/dev/ttyRightFollower \
     --robot.id=jt_follower_arm_right
   ```

2. 修改采集脚本，使用独立的 ID：
   ```bash
   # 修改第119行
   --robot.id=jt_follower_arm \   # 删除这行
   
   # 改为左右臂分别指定
   --robot.left_arm_config.id=jt_follower_arm_left \
   --robot.right_arm_config.id=jt_follower_arm_right \
   ```

## 📝 总结

**最快解决方法**：手动禁用 Follower 扭矩，调整到合适初始位置后重新开始。
