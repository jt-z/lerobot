# 数据采集脚本使用说明

## 任务描述
**任务**：Put the cap back on the pen on the table and place it in the pen holder  
**中文**：将笔帽盖回桌上的笔，然后放入笔筒

## 基本使用

### 首次采集
```bash
cd /home/jt/dev/lerobot/self_scripts
./collect_cap_pen_data.sh
```

### 中断后继续录制 ✅
```bash
./collect_cap_pen_data.sh --resume
```

**重要**：`--resume` 参数会：
- 加载已有数据集
- 自动从上次中断的 episode 继续
- 保持所有配置和校准文件一致
- 继续上传到同一个 Hugging Face 数据集

## 采集参数

| 参数 | 值 | 说明 |
|------|---|------|
| 数据集名称 | `jt-z/cap_pen_and_put_into_holder` | Hugging Face Hub 数据集 ID |
| Episode 数量 | 50 | 总共采集 50 个 episodes |
| 每 Episode 时长 | 60 秒 | 录制时长 |
| 重置时长 | 60 秒 | 环境重置时间 |
| 采集频率 | 30 Hz | 数据采集频率 |
| 摄像头 | 4 个 | 左臂 3 个 + 右臂 1 个 |

## 摄像头配置

| 位置 | 设备 | 分辨率 | 说明 |
|------|------|--------|------|
| 左臂手部 | `/dev/video0` | 640x480 | 左臂腕部视角 |
| 左臂顶部 | `/dev/video2` | 640x480 | 俯视视角 |
| 前视 | `/dev/video6` | 640x480 | 前方视角（挂载到左臂）|
| 右臂手部 | `/dev/video4` | 640x480 | 右臂腕部视角 |

## 采集流程

### 1. 脚本自动检查
- ✅ 串口连接（4个：左右 Follower + 左右 Leader）
- ✅ 摄像头设备（4个）
- ✅ 校准文件
- ✅ 显示参数总览和预计时长

### 2. 开始录制
- 按 ENTER 开始每个 episode
- 使用 Leader 臂控制 Follower 臂执行任务
- 可以使用快捷键提前结束或重录当前 episode

### 3. 重置环境
- 每个 episode 结束后有 60 秒重置时间
- 将物体和机械臂恢复到初始状态

### 4. 自动保存和上传
- 数据自动保存到本地
- 自动编码为 h264 视频
- 自动上传到 Hugging Face Hub

## 中断继续录制示例

### 场景 1：录制到第 20 个 episode 时断电
```bash
# 重新启动后，使用 --resume 继续
./collect_cap_pen_data.sh --resume

# 系统会：
# 1. 加载已有的 20 个 episodes
# 2. 从第 21 个 episode 开始继续录制
# 3. 直到完成总共 50 个 episodes
```

### 场景 2：录制到第 35 个 episode 时需要休息
```bash
# 按 Ctrl+C 中断
# 休息后继续：
./collect_cap_pen_data.sh --resume
```

### 场景 3：录制完成，想追加更多数据
```bash
# 修改脚本中的 NUM_EPISODES 为更大的数字（如 100）
# 然后使用 --resume
./collect_cap_pen_data.sh --resume

# 系统会从第 51 个 episode 继续录制到 100
```

## 数据质量建议

### 操作技巧
1. **流畅控制**：避免急停和突然改变方向
2. **稳定节奏**：保持匀速操作
3. **任务完整**：确保每个 episode 都完成任务

### 环境设置
1. **初始一致**：每个 episode 的起始位置尽量相似
2. **光照稳定**：保持光照条件一致
3. **适度变化**：物体位置可以有轻微变化（增加泛化）

### 数据多样性
1. 不同抓取角度
2. 不同放置位置
3. 可包含轻微失败后的纠正动作

## 常见问题

### Q1: 如何知道已经录制了多少个 episodes？
A: 可以查看 Hugging Face Hub 上的数据集，或使用：
```bash
python -c "
from lerobot.datasets.lerobot_dataset import LeRobotDataset
dataset = LeRobotDataset('jt-z/cap_pen_and_put_into_holder')
print(f'已录制: {dataset.num_episodes} episodes')
"
```

### Q2: 中断后数据会丢失吗？
A: 不会。每个 episode 完成后都会立即保存。只有当前正在录制的 episode（未完成）会丢失。

### Q3: 可以修改采集参数后继续吗？
A: 不建议。使用 `--resume` 时应保持所有参数（摄像头、FPS、串口等）与之前一致，否则可能导致数据不一致。

### Q4: 如何重新开始采集（不继续）？
A: 不使用 `--resume` 参数，直接运行脚本会创建新的数据集。记得修改 `DATASET_NAME`。

```bash
# 或在脚本中添加
--dataset.root=/path/to/your/custom/location
```
