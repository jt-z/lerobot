# SO-101 双臂协作机制代码流程分析

## 概述

LeRobot 代码库包含 SO-ARM 的双臂（bimanual）实现，不仅支持单臂操作，还提供完整的双臂协作控制机制。这是直接驱动实际硬件的双臂控制代码，而非仅用于仿真。

## 核心结论

### 硬件接口
- **底层通信**：使用 Feetech/Dynamixel 风格的串口 SDK（`scservo_sdk`）直接与电机通讯
- **操作类型**：读写寄存器、设置工作模式、读取 `Present_Position`、写入 `Goal_Position` 等
- **实现位置**：`src/lerobot/motors/feetech/feetech.py`
- **特性**：面向真实电机的实现，非仿真接口

### 双臂封装
- **实现类**：`BiSOFollower`（`src/lerobot/robots/bi_so_follower/bi_so_follower.py`）
- **架构**：通过创建两个 `SOFollower` 实例（left/right）实现双臂控制
- **命名约定**：action/observation 使用 `"left_"`/`"right_"` 前缀区分并分别委托到底层单臂实现

### 动作管线
- **处理流程**：一套处理器（processor）将高层 policy 输出逐步转换成电机关节目标
- **输入类型**：支持末端执行器（ee）相对增量或绝对目标
- **关键文件**：
  - `src/lerobot/robots/so_follower/robot_kinematic_processor.py`
  - `src/lerobot/processor/*`

## 详细流程：从 Policy 到电机命令

### 1. 高层输出（Policy / 控制器）

Policy 可以输出两类动作表示：

#### 末端执行器层级命令（`ee.*`）
- `enabled`：启用标志
- `target_x/y/z`：位置目标（用于增量控制）
- `target_wx/wy/wz`：旋转目标（轴角表示）
- `gripper_vel`：夹爪速度

#### 直接关节目标
- `motor_name.pos`：各电机的位置命令

这些动作进入处理器流水线（processor pipeline）。

### 2. 动作处理器流水线

位置：`robot_kinematic_processor.py` + `processor/` 目录

#### 2.1 EEReferenceAndDelta（`ee_reference_and_delta`）
**文件**：`robot_kinematic_processor.py:37-183`

**功能**：
- 将相对增量（`target_*`）应用到参考位姿生成绝对 `ee.pose`（`ee.x..ee.wz`）
- 支持两种模式：
  - `use_latched_reference=True`：在首次启用时锁定参考位姿
  - `use_latched_reference=False`：始终使用当前位姿作为参考

**关键代码**：
```python
# Line 100: 通过 FK 获取当前位姿
t_curr = self.kinematics.forward_kinematics(q_raw)

# Line 129-132: 应用增量到参考位姿
delta_p = np.array([tx * step_sizes["x"], ty * step_sizes["y"], tz * step_sizes["z"]])
r_abs = Rotation.from_rotvec([wx, wy, wz]).as_matrix()
desired[:3, :3] = ref[:3, :3] @ r_abs
desired[:3, 3] = ref[:3, 3] + delta_p
```

#### 2.2 EEBoundsAndSafety（`ee_bounds_and_safety`）
**文件**：`robot_kinematic_processor.py:186-249`

**功能**：
- 对生成的 `ee.pose` 进行工作空间边界裁剪
- 跳变检查（最大步长限制 `max_ee_step_m`，默认 0.05m）

**关键代码**：
```python
# Line 222: 裁剪位置到边界
pos = np.clip(pos, self.end_effector_bounds["min"], self.end_effector_bounds["max"])

# Line 225-230: 防止大幅跳变
if self._last_pos is not None:
    dpos = pos - self._last_pos
    n = float(np.linalg.norm(dpos))
    if n > self.max_ee_step_m and n > 0:
        pos = self._last_pos + dpos * (self.max_ee_step_m / n)
```

#### 2.3 GripperVelocityToJoint（`gripper_velocity_to_joint`）
**文件**：`robot_kinematic_processor.py:342-401`

**功能**：
- 将夹爪速度命令积分成 `gripper_pos`（关节位置）
- 支持离散夹爪模式（0: 打开, 1: 关闭, 2: 保持）

**关键代码**：
```python
# Line 386-388: 速度积分为位置
delta = gripper_vel * float(self.speed_factor)
gripper_pos = float(np.clip(q_raw[-1] + delta, self.clip_min, self.clip_max))
```

#### 2.4 InverseKinematicsEEToJoints（`inverse_kinematics_ee_to_joints`）
**文件**：`robot_kinematic_processor.py:252-338`

**功能**：
- 使用 `RobotKinematics` 将 `ee.pose` 转换为关节空间 `q_target`
- 按 `motor_names` 顺序映射到各电机

**关键代码**：
```python
# Line 306-308: 构建目标变换矩阵
t_des = np.eye(4, dtype=float)
t_des[:3, :3] = Rotation.from_rotvec([wx, wy, wz]).as_matrix()
t_des[:3, 3] = [x, y, z]

# Line 311: 逆运动学求解
q_target = self.kinematics.inverse_kinematics(self.q_curr, t_des)

# Line 315-319: 映射到电机位置
for i, name in enumerate(self.motor_names):
    if name != "gripper":
        action[f"{name}.pos"] = float(q_target[i])
```

```python
def send_action(self, action: RobotAction) -> RobotAction:
    # 移除 "left_" 前缀
    left_action = {
        key.removeprefix("left_"): value 
        for key, value in action.items() 
        if key.startswith("left_")
    }
    
    # 移除 "right_" 前缀
    right_action = {
        key.removeprefix("right_"): value 
        for key, value in action.items() 
        if key.startswith("right_")
    }
    
    # 分别发送到左右臂
    sent_action_left = self.left_arm.send_action(left_action)
    sent_action_right = self.right_arm.send_action(right_action)
    
    # 添加前缀并合并返回
    prefixed_sent_action_left = {f"left_{key}": value for key, value in sent_action_left.items()}
    prefixed_sent_action_right = {f"right_{key}": value for key, value in sent_action_right.items()}
    
    return {**prefixed_sent_action_left, **prefixed_sent_action_right}
```

```python
def send_action(self, action: RobotAction) -> RobotAction:
    # 提取目标位置（移除 ".pos" 后缀）
    goal_pos = {key.removesuffix(".pos"): val for key, val in action.items() if key.endswith(".pos")}
    
    # 安全限制：防止大幅跳变
    if self.config.max_relative_target is not None:
        present_pos = self.bus.sync_read("Present_Position")
        goal_present_pos = {key: (g_pos, present_pos[key]) for key, g_pos in goal_pos.items()}
        goal_pos = ensure_safe_goal_position(goal_present_pos, self.config.max_relative_target)
    
    # 发送目标位置到电机
    self.bus.sync_write("Goal_Position", goal_pos)
    return {f"{motor}.pos": val for motor, val in goal_pos.items()}
```

#### 配置电机（`configure`）
**代码**：Line 156-171

```python
def configure(self) -> None:
    with self.bus.torque_disabled():  # 安全上下文：配置时禁用扭矩
        self.bus.configure_motors()
        for motor in self.bus.motors:
            self.bus.write("Operating_Mode", motor, OperatingMode.POSITION.value)
            # 降低 P 系数避免抖动（默认 32，设为 16）
            self.bus.write("P_Coefficient", motor, 16)
            self.bus.write("I_Coefficient", motor, 0)
            self.bus.write("D_Coefficient", motor, 32)
            
            if motor == "gripper":
                # 夹爪保护：限制扭矩和电流防止烧毁
                self.bus.write("Max_Torque_Limit", motor, 500)  # 50% 最大扭矩
                self.bus.write("Protection_Current", motor, 250)  # 50% 最大电流
                self.bus.write("Overload_Torque", motor, 25)  # 过载时 25% 扭矩
```

#### 校准流程（`calibrate`）
**代码**：Line 112-154

```python
def calibrate(self) -> None:
    if self.calibration:
        # 如果存在校准文件，询问是否使用
        user_input = input("Press ENTER to use calibration file or 'c' to run calibration: ")
        if user_input.strip().lower() != "c":
            self.bus.write_calibration(self.calibration)
            return
    
    # 运行新校准
    self.bus.disable_torque()
    for motor in self.bus.motors:
        self.bus.write("Operating_Mode", motor, OperatingMode.POSITION.value)
    
    # 设置中点归位
    input("Move robot to middle of range and press ENTER...")
    homing_offsets = self.bus.set_half_turn_homings()
    
    # 记录运动范围（除 wrist_roll 外）
    full_turn_motor = "wrist_roll"
    unknown_range_motors = [motor for motor in self.bus.motors if motor != full_turn_motor]
    print("Move joints through full range. Press ENTER to stop...")
    range_mins, range_maxes = self.bus.record_ranges_of_motion(unknown_range_motors)
    range_mins[full_turn_motor] = 0
    range_maxes[full_turn_motor] = 4095
    
    # 保存校准数据
    self.calibration = {
        motor: MotorCalibration(
            id=m.id,
            drive_mode=0,
            homing_offset=homing_offsets[motor],
            range_min=range_mins[motor],
            range_max=range_maxes[motor],
        )
        for motor, m in self.bus.motors.items()
    }
    
    self.bus.write_calibration(self.calibration)
    self._save_calibration()
```

## 安全保护机制

### 1. 扭矩禁用上下文（`torque_disabled()`）
在写入某些寄存器或校准时先禁用扭矩，避免伤人或损坏设备。

```python
with self.bus.torque_disabled():
    # 安全配置操作
    self.bus.configure_motors()
```

### 2. 相对目标限制（`max_relative_target`）
在 `SOFollower.send_action` 中限制单步移动幅度。

```python
if self.config.max_relative_target is not None:
    present_pos = self.bus.sync_read("Present_Position")
    goal_pos = ensure_safe_goal_position(goal_present_pos, self.config.max_relative_target)
```

### 3. 末端执行器边界与安全（`EEBoundsAndSafety`）
在笛卡尔空间层面限制位置范围和最大步长。

### 4. 夹爪保护
配置夹爪的扭矩限制、保护电流和过载扭矩，防止烧毁：

```python
if motor == "gripper":
    self.bus.write("Max_Torque_Limit", motor, 500)     # 50% 最大扭矩
```

## 补充说明

### 真实硬件 vs 仿真
- **真实硬件驱动**：包含 motor bus、串口、scservo SDK、PID/工作模式配置、校准交互
- **上层算法/处理器**：包含 IK/FK、EE↔Joint 转换、动作裁剪、特征变换
- **仿真支撑**：仓库也有 `envs/rl/policies` 等模块用于训练或仿真流水，但 SOFollower/Feetech 明确面向真实硬件

### 使用注意事项
1. 需要将硬件串口和电机正确连接
2. 按照 `setup_motors` 指南配置电机 ID
3. 运行 `calibrate` 进行校准（需人工确认）
4. 确保安全保护机制已启用
5. 测试时先使用 `max_relative_target` 限制移动幅度

### 相关硬件信息
- **SO-ARM 系列**：SO-100/SO-101/SO-10X
- **电机型号**：Feetech STS3215
- **通信协议**：基于 Dynamixel Protocol（支持 Protocol 0 和 1）
- **控制模式**：位置控制（主要）、速度控制、PWM 控制、步进控制
