二、左臂 B601-RS（从臂）+ StarArm102（主臂）
------------------------------------------------------------
  从臂端口：can0（SocketCAN，PEAK PCAN-USB，lsusb 0c72:000c）
  从臂配置：经典 CAN 2.0，1Mbps，不支持 CAN FD
            sudo ip link set can0 down
            sudo ip link set can0 type can bitrate 1000000
            sudo ip link set can0 up
  主臂端口：/dev/ttyUSB0（CH340 1a86:7523，无序列号）
            by-id：/dev/serial/by-id/usb-1a86_USB_Serial-if00-port0
            无读权限时：sudo chmod 666 /dev/ttyUSB0（需先 sudo apt remove brltty）
  lerobot 类型：
    robot  = bi_b601_so101_follower 的 left_arm_config（seeed_b601_rs_follower）
    teleop = bi_b601_so101_leader 的 left_arm_config（rebot_102_leader）
  校准文件：~/.cache/huggingface/lerobot/calibration/robots/seeed_b601_rs_follower/follower.json
            采集/推理用 id=jt_follower_arm → jt_follower_arm_left.json
            主臂 id=jt_leader_arm → jt_leader_arm_left.json
  关键参数：gravity_compensation=true；joint_directions 全 -1.0（见 self_scripts/b601_so101_bimanual/02_record.sh）
